# ASIEXP
A 3D-designed astronaut spacesuit concept built in Tinkercad, featuring a detailed helmet, gold-accented visor, chest controls, articulated gloves, reinforced joints, specialised boots, and a rear life-support backpack. Designed for future interstellar exploration, with distinctive Indian identity details.
